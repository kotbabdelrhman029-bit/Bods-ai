# bods AI — النسخة المقوّاة (v22)

مساعد ذكي متكامل: **شات · كود · وكيل · تصميم · صور · فيديو · صوت**  
تطبيق أندرويد حقيقي + ويندوز/ماك/لينكس + موقع ويب.  
المستخدم **مش بيحط مفاتيح** — المفاتيح على سيرفرك فقط.

---

## أهم حاجة: السيرفر الخاص بيك (عشان يرد على الرسائل)

بدون سيرفر متصل → التطبيق مش هيرد. ده طبيعي ومقصود للأمان.

### نشر سريع على Render (موصى به)

1. ارفع المشروع على GitHub (من غير `.env`)
2. [render.com](https://render.com) → **New → Web Service** → اربط المستودع
3. الإعدادات:
   - Build: `npm install`
   - Start: `npm start`
   - Environment Variables:
     | المفتاح | القيمة |
     |---------|--------|
     | `GEMINI_API_KEY` | مفتاحك من Google AI Studio |
     | `REQUIRE_LOGIN` | `0` (بدون تسجيل في البداية) |
     | `DAILY_LIMIT` | `50` |
     | `ALLOWED_ORIGINS` | `*` |
     | اختياري | `OPENAI_API_KEY` / `XAI_API_KEY` / `ANTHROPIC_API_KEY` … |
4. بعد النشر انسخ الرابط → حطه في `public/config.js`:
   ```js
   window.BODS_API_BASE = "https://xxxxx.onrender.com";
   ```
5. أعد بناء الموقع/التطبيق.

### تشغيل محلي

```bash
cp .env.example .env
# عدّل .env وحط GEMINI_API_KEY على الأقل
npm install && npm start
```
افتح http://localhost:3000  
وفي config.js: `window.BODS_API_BASE = "http://localhost:3000";`

### بديل: Cloudflare Worker

الصق `worker/worker.js` في Cloudflare Workers، أضف Secrets، وحط الرابط في config.js.

## الأذونات (أندرويد)

من داخل التطبيق: **☰ ← الإعدادات ← الأذونات ← تفعيل كل الأذونات الآن**  
هتظهر رسالة النظام (سماح) مباشرة.  
لو اترفضت نهائياً: إعدادات الجهاز ← التطبيقات ← bods AI ← الأذونات.
